# 开源项目

日常参考的开源项目整理，来自原"资源-外部教程"收藏。

## 若依 ruoyi

- 官网文档：<https://doc.ruoyi.vip/>
- 简介：基于 Spring Boot + Vue 的快速开发平台，前后端分离，包含代码生成、权限管理等脚手架能力，适合快速搭建企业后台管理系统。

## mall

- 官网文档：<https://www.macrozheng.com/>
- 简介：一套电商系统实战教程与脚手架，涵盖 Spring Boot 后端、Vue 管理后台、小程序/App 端，适合学习完整电商业务与技术栈。

## 芋道 yudao

- 官网文档：<https://doc.iocoder.cn/>（ruoyi-vue-pro）
- 云平台版：<https://cloud.iocoder.cn/>（yudao-cloud）
- 简介：基于若依脚手架深度定制的一站式 Java 快速开发平台，提供单体（ruoyi-vue-pro）与微服务（yudao-cloud）两套版本，内置系统管理、代码生成等模块。

## 马士兵

- 官网文档：<https://www.mashibing.com/sf/pc.html>
- 简介：Java 全栈方向的技术学习资料与体系课程整理入口。
