### 常见问题

**Maven 本地仓库识别错误**

新版 IDEA 启动时默认把本地仓库识别为 C 盘用户目录下的 `.m2\repository`，需要手动点击 `Reload All Maven Projects` 才会读取 D 盘配置的本地仓库。

解决方案：删除 C 盘 `.m2\repository` 目录，用管理员 CMD 建立符号链接：

```bat
mklink /D "C:\Users\用户名\.m2\repository" "D:\.m2\repository"
```
