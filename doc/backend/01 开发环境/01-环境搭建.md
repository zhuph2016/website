## Maven

### 下载与安装

- 下载：https://maven.apache.org/download.cgi
- 环境变量：

```
MAVEN_HOME  C:\Program Files\apache-maven-3.6.3
Path        %MAVEN_HOME%\bin
```

验证安装：`mvn -v`

### 阿里云镜像（settings.xml）

在 `~/.m2/settings.xml` 或 Maven 安装目录 `conf/settings.xml` 中配置：

```xml
<mirrors>
  <mirror>
    <id>aliyunmaven</id>
    <mirrorOf>*</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

### 本地仓库

```xml
<localRepository>D:\<本地仓库目录></localRepository>
```

## MySQL

### 下载与安装

- 官方下载：https://dev.mysql.com/
- 历史版本归档：https://downloads.mysql.com/archives/community/
- 安装指南：https://zhuanlan.zhihu.com/p/37152572
- 安装方式：编译安装 / rpm / yum / 压缩包

### 环境变量

```
Path += C:\Program Files\MySQL\MySQL Server 8.0\bin
```

### 配置文件 my.ini

```ini
[mysql]
# 设置3306端口
port=3306
# 设置mysql的安装目录
basedir=C:\Program Files\MySQL
# 设置mysql数据库的数据的存放目录
datadir=C:\Program Files\MySQL
# 允许最大连接数
max_connections=200
# 允许连接失败的次数
max_connect_errors=10
# 服务端使用的字符集默认为utf8
character-set-server=utf8
# 创建新表时将使用的默认存储引擎
default-storage-engine=INNODB
# 默认使用"mysql_native_password"插件认证
default_authentication_plugin=mysql_native_password

[mysql]
# 设置mysql客户端默认字符集
default-character-set=utf8

[client]
# 设置mysql客户端连接服务端时默认使用的端口
port=3306
default-character-set=utf8
```

### 命令行安装（管理员身份运行 CMD）

```bat
cd C:\Program Files\MySQL
mysqld --initialize --console     :: 初始化，会生成随机密码
mysqld --install mysql            :: 安装服务
net start mysql                   :: 启动服务
mysql -uroot -p                   :: 登录（手动输入上面的随机密码）
ALTER USER 'root'@'localhost' IDENTIFIED BY '<新密码>';   :: 修改登录密码
exit
```

### 客户端连接报错 2059（authentication plugin 'caching_sha2_password'）

MySQL 8 默认加密规则为 `caching_sha2_password`，旧版 Navicat 不支持，需改回 `mysql_native_password`：

```sql
-- 查看加密方式
show variables like 'default_authentication_plugin';
-- 查看本地 mysql 用户信息
select host,user,plugin from mysql.user;
-- 修改 root 账户加密方式
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'root';
-- 或完整重置（含密码过期策略）
ALTER USER 'root'@'localhost' IDENTIFIED BY 'password' PASSWORD EXPIRE NEVER;
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'password';
FLUSH PRIVILEGES;
```

参考：https://jingyan.baidu.com/article/0aa22375e7966ac8cc0d64b3.html

### 时区问题

- JDBC 连接串需加时区参数：`serverTimezone=Asia/Shanghai`
- mysql-connector-java 5.x 以上版本：`serverTimezone=GMT%2B8`
- 参考：https://blog.csdn.net/zjy_love_java/article/details/107704594、https://blog.csdn.net/lan861698789/article/details/104770001/

### 常用命令与版本特性

```sql
SHOW CREATE TABLE user;   -- 查看建表语句
show PROCESSLIST;                        -- 查看连接进程
SHOW ENGINE INNODB STATUS;               -- 查看 InnoDB 状态（锁、事务、死锁）
```

## Node.js 与包管理工具

### 下载安装

- 官网：https://nodejs.org/en/
- 验证：`node -v`、`npm -v`
- 安装参考：https://www.jianshu.com/p/13f45e24b1de

### 修改 npm 全局路径

```bash
npm config ls
mkdir E:\nodejs\node_modules\npm\node_global_modules
mkdir E:\nodejs\node_modules\npm\node_cache

# prefix 对应全局模块目录，cache 对应缓存目录
npm config set prefix "D:\<你的目录>\node_modules\npm\node_global_modules"
npm config set cache  "D:\<你的目录>\node_modules\npm\node_cache"
```

### 包管理工具对比

| 工具 | 特点 | 安装 | 镜像源配置 |
| --- | --- | --- | --- |
| npm | Node 自带包管理器，从 npm 仓库拉取（国外，不稳定） | 随 Node 安装 | `npm config set registry https://registry.npmmirror.com` |
| npx | npm 5.2+ 自带，快捷运行包内 CLI 工具 | `npm install -g npx` | - |
| cnpm | 淘宝镜像版 npm，定时同步国外仓库 | `npm install -g cnpm --registry=https://registry.npmmirror.com` | 默认走 npmmirror |
| yarn | 缓存已下载的包，并行执行，安装更快 | `npm install --global yarn` | `yarn config set registry https://registry.npmmirror.com` |
| pnpm | 依赖存于内容可寻址存储，节省磁盘、安装快 | `npm install -g pnpm` 或 `iwr https://get.pnpm.io/install.ps1 -useb \| iex` | `pnpm config set registry https://registry.npmmirror.com` |

**常用命令**

- npm：`npm install <name>`；项目临时换源：`npm install --registry https://registry.npmmirror.com`
- yarn：`yarn add` 装包 / `yarn remove` 卸包；`yarn config get registry` 查看源 / `yarn config delete registry` 删除源
- pnpm：`pnpm add` 安装软件包及依赖 / `pnpm install`（别名 i）按声明安装全部依赖 / `pnpm update` 更新依赖
- pnpm 源配置：`pnpm config list`（管理配置文件）、`pnpm config get registry`、`pnpm config set registry https://registry.npmmirror.com`
