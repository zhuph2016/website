# 面试日记

按日期记录面试实录 / 视频学习中**不知道的知识点**，保留时间线，方便回溯和定期回填。

## 记录格式

```markdown
## YYYY-MM-DD ｜ 来源：xxx（视频 / 文章 / 链接）

- ❌ 不懂：知识点名称
  - 回填：doc/backend/... （已沉淀到对应文档时写路径）
  - 状态：待整理 / 已回填
```

## 使用说明

- 看面试视频 / 文章时，只记"不知道的"和"答不上的"，随手记，不追求完整
- 定期（如每周）把已消化的知识点**回填**到 `backend/` 对应技术文档，或提炼到 [questions/](./questions/) 主题题集
- 面试后复盘：记下面试官问了什么、自己哪里卡壳，下次重点补
